Computer's log

    How to play
    • A secret code of 4 pegs is chosen from 6 colors. Colors can repeat (you can turn repeats off in Options).
    • You get 10 guesses. Fill the glowing row, then tap Check. Tap a placed peg to select it; tap it again to remove it.
    • Each guess earns key pegs: red = right color in the right hole, white = right color in the wrong hole. Reds are always shown first, so their position tells you nothing about which peg they mean.
    • Each peg scores at most once. If the code has one blue and you guess two blues, only one of them can earn a key peg.
    • Hint fills in the guess that leaves the fewest possible codes in the worst case (Knuth's method). Give up lets the computer finish the game and counts as a loss.
    • Set the code flips the roles: pick a secret and watch the computer crack it. With repeats on, it never needs more than 5 guesses.
    • Keyboard: 1–6 place colors, ←/→ move, Backspace clears, Enter checks, H for a hint.
